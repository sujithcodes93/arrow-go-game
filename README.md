# Arrow Go Game

A simple web game where you move around the board with the arrow keys or buttons, collect glowing stars, avoid obstacles, and try to reach a score of 5 before the timer runs out.

## How to run

1. Open a terminal in this folder.
2. Run:
   ```bash
   python3 -m http.server 8000
   ```
3. Open your browser to:
   ```text
   http://localhost:8000
   ```

## Controls

- Arrow keys on your keyboard
- On-screen arrow buttons for touch devices

## Goal

- Collect 5 stars
- Avoid the red obstacle tiles
- Beat the countdown timer

## Files

- `index.html` — page layout
- `style.css` — styles and game visuals
- `script.js` — game logic
